Recommended setup — app public, vault private
This app can be hosted publicly (e.g. GitHub Pages) while your financial data stays in a completely separate private repository. Only you can access the vault.
  1. Host the app publicly — fork or upload index.html to a public GitHub repo, enable GitHub Pages under Settings → Pages → Deploy from branch.
  2. Create a private vault repo — go to github.com/new, name it something generic (e.g. v-store), set it to Private, and initialise with a README so it exists.
  3. Create a fine-grained Personal Access Token — go to GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new. Set:
     · Resource owner: your account
     · Repository access: Only select repositories → choose your private vault repo only
     · Permissions: Contents → Read and write
    This token can read/write your vault repo and nothing else.
  4. Choose a strong passphrase — use 5 or more random words (diceware) or a random 20+ character string. This is the only thing protecting your data if someone downloads the encrypted file. Do not reuse a password from anywhere else.
  5. Fill in the form below — enter the token, passphrase, and the private vault repo owner/name. Click Test, then Open vault.
⚠ Your passphrase cannot be recovered. If you forget it, the vault file cannot be decrypted. Store it in a password manager.

💡 5 steps to grow your money
1
Emergency fund — 3–6 months of expenses
Keep in a high-yield savings account. At ECB rates, eurozone accounts pay 3–4%. This is your safety net before anything else — without it, any shock forces you to sell investments at the worst moment.
2
Employer pension match (if available) verify manually
100% instant return on every matched euro. Always max this before investing elsewhere. If your employer doesn't offer it, skip to step 3.
3
Pay down high-interest debt (>5–6%)
Your mortgage spread checker shows what your loan actually costs. Anything above 5–6% annual rate delivers a guaranteed return when paid down — better than most investments. Negotiate your mortgage spread or refinance if it's too high.
4
Tax-advantaged accounts (Austria: Zukunftsvorsorge) verify manually
The government subsidises contributions — it's free money. Max the annual limit before investing in a regular broker account.
5
Broad index funds — MSCI World or S&P 500 ETF
Low cost, well diversified, 7–10% historical nominal return over the long run. Use a low-fee broker (Flatex, DADAT, or similar). Only invest money you won't need for 5+ years. Individual stocks, crypto, and real estate come after this — not before.
This is general information, not personalised financial advice. Consult a qualified advisor for your specific situation.

Self-test
Internal integrity checks — duplicate element ids, duplicate function declarations, inline event handlers pointing at functions that don't exist, and schema migration correctness. The same checks an AI assistant would run by hand after editing this file.
What to do if a test fails
Duplicate ids: Two HTML elements share the same id — el() calls for that id are unpredictable. Find and rename one.
Duplicate functions: The same function is declared twice — the second silently overrides the first. Search for the name and remove one declaration.
Missing handler fns: An onclick/oninput etc. references a function that doesn't exist — clicking that element will throw. Usually caused by a rename without updating the HTML. Fix the handler or restore the function name.
Migration failure: A step in the MIGRATIONS array threw an error or isn't idempotent. Check the newest migration step — it must be a pure function that handles already-migrated data gracefully.
Utility failures: A core helper returned an unexpected value — likely broken by a recent edit. Restore the function from git or the previous working file.

Switch vault repository
Move your vault to a different GitHub repository — for example from a public repo to a private one. Your data is re-encrypted with your current passphrase and pushed to the new location. The old repository file is not deleted.
Your token must have Contents: read & write permission on the new repository. The vault file will be created as budget.enc. After switching, point your token scope to the new repo only.
